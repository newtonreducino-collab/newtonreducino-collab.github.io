Claude Gmail Pessoal

Aplicativo de uso pessoal de Newton Reducino. Ele permite que o assistente Claude, rodando no computador do próprio Newton, organize a caixa de e-mail pessoal dele no Gmail (buscar, ler, aplicar marcadores, criar filtros, mover para a Lixeira e criar rascunhos).

O aplicativo não é oferecido ao público. Só a conta do próprio Newton é autorizada a usá-lo.

Política de Privacidade

Quais dados são acessados: mensagens, marcadores e filtros da conta Gmail que o próprio dono autorizou, pelos escopos gmail.modify e gmail.settings.basic.

Como são usados: só para organizar a caixa de e-mail a pedido do dono da conta. O aplicativo não envia e-mails e não apaga mensagens de forma definitiva.

Onde ficam: a autorização fica salva apenas no computador do dono. Nenhum dado é guardado em servidor do aplicativo, vendido ou compartilhado com terceiros, nem usado para publicidade.

Uso de dados do Google: o uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar: a qualquer momento, em myaccount.google.com/permissions.
